1. The problem: a fragmented data stack

A story: Aarav's retail company

Aarav works for a mid-size retailer. Sales data sits in SQL Server. Web orders sit in a cloud database. Marketing exports CSV files. To get one report, the team:

  1. Uses an ETL tool to copy data into a data lake.
  2. Uses a Spark platform to clean it.
  3. Loads it again into a separate warehouse.
  4. Copies it once more into a BI tool for dashboards.

Now the same "Total Sales" number exists in four places. When they disagree, nobody knows which is right.

What goes wrong in a fragmented stack
  • Duplicate data: every tool keeps its own copy, so storage costs rise and numbers drift.
  • Many security models: permissions are set separately in each tool, which is error-prone.
  • Many bills: each service is priced and monitored differently.
  • Integration glue: engineers spend time connecting tools instead of delivering insight.
  • Skill sprawl: the team must learn a different product for every step.
  • Slow delivery: each hand-off between tools adds delay and failure points.

Fabric's idea: keep every step on one platform, working over one copy of the data.

2. What is Microsoft Fabric?

Microsoft Fabric is an end-to-end, SaaS analytics platform. It covers data movement, data engineering, data warehousing, real-time analytics, data science and business intelligence in a single product.

☁️ SaaS
Software as a Service. Microsoft runs the infrastructure. You do not create storage accounts, size clusters, or patch servers. You sign in and create items.
🧩 Unified
All workloads share one portal, one workspace model, one security and governance layer, and one billing model based on capacity.
🗄 OneLake
One logical data lake per organization, often called "OneDrive for data". Data is stored once, in the open Delta Parquet format, and every engine can read it.
💡 Analogy: Old approach: carrying a camera, GPS, music player and phone. Fabric: one smartphone. The features work together, share one battery (capacity) and one storage (OneLake).

Key benefits

  • Less setup: start building in minutes.
  • Single copy of data: less duplication, fewer disagreements.
  • Open format: Delta Parquet avoids lock-in to one engine.
  • One governance layer: consistent security, lineage and sensitivity labels.
  • Built-in AI: Copilot assists across workloads (covered in Session 4).
  • Tight Power BI integration: reports can read lake data directly (Direct Lake, Module 12).

Read it bottom-up: capacity supplies compute, OneLake stores data once, shared services apply governance, and the workloads on top are just different ways of working with the same data. (Session 3 goes deeper.)

🧪 Lab 1: Your first Fabric workspace

Time: 20 minutes · Needs: a work or school account and a browser (Edge or Chrome).

  1. Open app.fabric.microsoft.com and sign in. Expected: the Fabric home page loads.
  2. Click your profile picture (top right) and start the Fabric trial. The free trial runs for 60 days, which covers this whole course. If the option is missing, ask your admin to enable it in the Admin Portal, or use a capacity your organization provides.
  3. Confirm the trial capacity was created. Expected: a message showing the trial period and your capacity.
  4. Open Workspaces → New workspace and name it FabricTraining-YourName.
  5. In the workspace settings, open License info and choose your trial capacity.
  6. Explore the left menu: Home, OneLake, Monitor, Workspaces. Open the + New item menu and note which workloads appear.

✅ Checkpoint: a diamond capacity icon appears next to your workspace name, and + New item lists Lakehouse, Warehouse, Notebook and more. Take a screenshot for your assignment.

🛠 Common problems and fixes
  • No trial option: a tenant admin has disabled it. Ask them to allow users to try Fabric features.
  • Personal Gmail/Outlook rejected: use a work or school (Entra ID) account, or a Microsoft 365 developer tenant.
  • Cannot assign capacity: you need workspace admin rights and permission on the capacity.
  • No Fabric items in + New: the workspace is not on a Fabric capacity. Repeat step 5.

📝 Self-check quiz

1. In one sentence, what problem does Fabric solve?It replaces a fragmented stack of separate tools, data copies, security models and bills with one platform working over one copy of data.
2. What does SaaS mean, and what do you stop managing?The vendor operates the service. You no longer provision, patch or scale servers, clusters or storage accounts.
3. What is OneLake, and which format does it use?Fabric's single logical data lake for the organization. Data is stored once in Delta Parquet.
4. Match: SSIS, Synapse dedicated pool, Azure Data Explorer.Data Factory, Warehouse, Real-Time Intelligence (Eventhouse/KQL).
5. Why is Fabric called "unified"?All workloads share one portal, workspaces, governance, storage layer and capacity billing.
6. Name two reasons a team might still choose Snowflake or stay on Synapse.Multi-cloud requirements or existing Snowflake skills and contracts; a stable Synapse estate with no urgent reason to migrate.
7. Is a Lakehouse a separate product from Fabric?No. It is an item inside Fabric's Data Engineering experience, stored in OneLake.
8. Interview style: "Why would a company adopt Fabric?"Model answer: to consolidate tools onto one SaaS platform with a single copy of data in open Delta format, simplify governance and billing, and integrate tightly with Power BI, while weighing migration effort and skills.
